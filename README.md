# Description
The get_next_line project consists of writing a function in C that reads from a file descriptor and returns one line at a time, ended by a newline character (\n), until the end of the file is reached.

# Instructions
To compile the project, you need to define the BUFFER_SIZE at compilation time using the -D flag:

        cc -Wall -Wextra -Werror -D BUFFER_SIZE=42 get_next_line.c get_next_line_utils.c main.c -o gnl
